## 1. App / store icons

Driven by [`app.json`](../app.json). Required for builds and store submission.

| File | Used for | Recommended size | Status |
|------|----------|------------------|:------:|
| `assets/images/icon.png` | iOS + main app icon | 1024×1024 | ✅ |
| `assets/images/adaptive-icon.png` | Android adaptive foreground (bg `#0B0A0F`) | 1024×1024, content in centered safe zone | ✅ |
| `assets/images/splash-icon.png` | Splash screen (renders at 240 wide, `contain`) | 480–720 wide, transparent | ✅ |
| `assets/images/favicon.png` | Web favicon | 48×48 / 64×64 | ✅ |

**Unused template leftovers** (present in folder, not wired into `app.json`):
`android-icon-background.png`, `android-icon-foreground.png`, `android-icon-monochrome.png`.
To enable a Material You themed icon, add `monochromeImage` to the `android.adaptiveIcon` block.
