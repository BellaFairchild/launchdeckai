## Product North Star

LaunchDeckAI is a calm, AI-powered launch deck for first-time app creators. It helps users know what to do next, what is missing, what needs to be created, and how close they are to launch.

## Core Product Loop

Deck → Missions → Blueprints → Foundry → Cargo Bay → Signal Deck → Copilot

## Key Naming Rules

Use LaunchDeckAI language consistently:

- Project = Mission
- Credits = Fuel
- Templates = Blueprints
- Asset hub = Cargo Bay
- AI tools = The Foundry
- Pricing = Refuel Station
- Signals = Signal Deck
- AI character = Astro
